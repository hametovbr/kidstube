Доступ

Как получить:
  1. console.cloud.google.com → новый проект
  2. «API и сервисы» → «Библиотека» → YouTube Data API v3 → «Включить»
  3. «Учётные данные» → «Создать» → «Ключ API»
Нужен для настроек и родительского меню на ТВ (долгое нажатие OK на видео).

Что блокировать

Регистр не важен, «ё» = «е». Срабатывает и часть слова: «страш» скроет «страшный» и «страшилки».
